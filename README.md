# 妖林绮梦 · Fantasy Forest

> 成人向奇幻 · 掷骰探索 · 回合战斗 · 浏览器游戏

**🔞 本游戏包含露骨的成人性内容、性幻想、暴力与身体状态描写，仅面向达到所在地法定成年年龄的玩家。**

## 简介

《妖林绮梦》是一款以**掷骰探索、路线选择与回合战斗**为核心的成人向奇幻浏览器游戏。

你的女友被森林拖走了。你必须穿越妖林，在岔路之间抉择方向，遭遇怪物、陷阱与宝藏，最终救回她。

- **掷骰移动**：掷 Y 决定移动格数，路线选择决定生死
- **回合战斗**：掷骰攻击，含 BPM 计时任务、状态效果、特殊机制
- **营地系统**：旅行商店、公共厕所（隐藏荣耀洞）、雾灯酒馆、篝火旁的鹿
- **成人内容**：酒馆打工、妓女系统、扶她佣兵等

## 玩法特色

- 三种难度：普通 / 困难 / 残酷
- 多目标战斗（哥布林群、魔女召唤物）
- 状态效果：中毒、混乱、醉倒、石化、困倦等
- 战斗任务：BPM 节拍 + 分段计时
- 营地：商店、厕所（荣耀洞）、酒馆（赌博 / 打工 / 招募）
- 妓女系统：许可证、等级称号、6 种顾客、妓女用品
- 佣兵系统：扶她战士芙蕾雅

## 技术说明

- 纯前端 HTML / CSS / JavaScript，无构建步骤
- 存档保存在浏览器 localStorage
- 打开 `index.html` 即可运行（建议用本地服务器避免跨域限制）
