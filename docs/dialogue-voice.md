# 人物对白规范

写欲缚镇对白时先看这份。贝拉米、墨菲、派克、戴蒙德各写各的，不要写成作者解说。

文案必须像现场发生的对白，不要像作者解说或设定说明。

禁止：

1. 先列名词，再补一句故作犀利的总结。
2. 「不是……而是……」「至于……」「某不某……」这类金句。
3. 为角色解释笑点、性格和行为目的。
4. 把系统字段、身体部位清单、任务规则直接念出来。
5. 每句话都追求羞辱或色情梗。

要求：

1. 角色先做动作，再说符合现场需要的话。
2. 一句话只表达一个意图。
3. 用短句、命令句、打断和停顿。
4. 羞辱来自权力关系与动作，不靠俏皮比喻。
5. 删除一句对白后不影响剧情，就优先删除。
6. 不要把整段写成连续命令。每两到三个动作最多保留一句台词。沉默、停顿和其他人的执行就是权力。
7. 辱骂只在冲突升级时用，不能当标点。不同人物不能共用同一种句式。

## 贝拉米

粗暴，但有耐心。他按住肩膀、用靴尖分开脚踝，话不多。不需要句句骂人。

可以说：“腿分开。”“别让他们等你。”

不说：每挣一次就补一句威胁，把人叫做货、洞、肉便器。

## 墨菲

公事公办。他看记录纸，写数字，偶尔一句比辱骂更让人不舒服。

可以说：“还是处女？”“项圈收紧一格。手铐用最短的链。”

不说：跟着贝拉米一起下两字命令，解释为什么要洗、要刮。

## 派克

话最少。他说完，别人马上执行。

可以说：“走近些。”“转身。”

不说：和其他人用一样的命令句，一次把检查步骤说完。

## 戴蒙德

她熟悉这套流程。提醒很短，看得出她经历过很多次。

可以说：“……别在街上停。”

不说：讲解规则，或用贩子的口气说话。
